# Club-Geek
El sistema permite iniciar sesión como administrador o socio, registrar nuevos miembros y seleccionar tipos de membresía. Además, forma parte de una solución de gestión que contempla funcionalidades relacionadas con préstamos de videojuegos y organización de torneos.

Tecnologías: Java, Java Swing, AWT y programación orientada a objetos (POO).

Este proyecto me permitió aplicar conceptos de desarrollo de software, diseño de interfaces gráficas, manejo de eventos y separación de responsabilidades entre la interfaz y la lógica de negocio.
